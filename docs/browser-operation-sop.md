# 浏览器操作 SOP

这份 SOP 只整理当前工作区里已经被本地成功案例验证过的路径。

## 先说结论

当前最近成功流程里的浏览器发布:

- 不是固定 Python 脚本主导
- 是 Codex 驱动浏览器自动化会话执行
- 平台差异很大
- 真正稳定的是:
  - 入口页
  - 必填字段
  - 手动检查点
  - 管理页验证标准

如果你要接管已经开着的现有标签页、半成品页、旧草稿页，不要只看这份总 SOP，直接同时看:

- [`browser-tab-takeover-runbook.md`](./browser-tab-takeover-runbook.md)

## 统一前置规则

所有平台先做这 6 步:

1. 不先开后台，先把内容包写完整
2. 打开后台前先查管理页，避免重复发同主题
3. 富文本和标题字段优先真实键盘输入
4. 风控、验证码、滑块、短信验证都视为手动检查点
5. 不以“点了发布”作为成功
6. 成功后立刻回填日志并推飞书

## 平台级 SOP

### 1. 微博

本地结论:

- 登录后流程相对直接
- 最近成功样本: `2026-04-08 18:35 -> 18:39`
- 验证标准: 主页流可见，最好拿到公开 URL

执行顺序:

1. 打开微博发布器
2. 选择视频发布
3. 上传主视频
4. 粘贴微博正文
5. 如封面不可单独上传，确保视频前几秒和正文第一屏一致
6. 发布
7. 回主页流验证是否可见

成功信号:

- 主页流可见
- 或拿到帖子直链

### 2. 抖音

本地规则:

- 发布前先看 `作品管理`
- 标题输入必须真实输入，不能只改 `input.value`
- `审核中` 算提交成功

执行顺序:

1. 进创作者后台
2. 先看 `作品管理` 顶部最近两条，确认没重复
3. 打开视频发布页
4. 上传视频
5. 填标题
6. 填描述
7. 设置封面
8. 用本地 prepared cover 做 `竖封面 3:4` 和 `横封面 4:3`
9. 点击发布
10. 回 `作品管理` 核验

成功信号:

- `作品管理` 新条目出现
- `审核中` 或已发布

### 3. 微信视频号

这是最容易假成功的平台，必须谨慎。

已验证入口:

- `https://channels.weixin.qq.com/login.html`
- `https://channels.weixin.qq.com/platform/post/create`
- `https://channels.weixin.qq.com/micro/content/post/list`

关键事实:

- 真实表单在 `iframe[name="content"]`
- 首页已登录，不代表 `post/create` 还可用
- `视频描述` 和 `短标题` 必须真实输入
- 同视频不能重复发布

执行顺序:

1. 打开 `login.html` 确认登录态
2. 进入 `platform/post/create`
3. 定位 `iframe[name="content"]`
4. 上传视频
5. 等待页面不再出现:
   - `请上传视频`
   - `取消上传`
   - `0%`
   - `文件上传中，请等待完成后再发表。`
6. 真实键盘输入:
   - `视频描述`
   - `短标题`
7. 打开封面编辑
   - 优先点击卡片里的 `编辑`
   - 再回退到 `编辑封面`
8. 在封面弹层里上传本地 3:4 封面
   - 本地经验里通常是第二个 `input[type="file"]`
9. 点击 `确定`
10. 等 `发表` 按钮解除禁用
11. 发表
12. 回 `micro/content/post/list` 验证

成功信号:

- create 页出现 `已发表`
- 或列表页出现新条目，右侧描述片段正确

硬规则:

- 如果 `视频管理` 已经有相同视频，立即停止，不重发

### 4. 快手

已验证入口:

- `https://cp.kuaishou.com/article/publish/video?tabType=1`

关键事实:

- 如果页面提示 `还有上次未发布的视频，是否继续编辑？`，优先续草稿
- 描述编辑器节点在本地验证里是 `#work-description-edit`
- 最终验证必须看 `作品管理`
- `审核中` 算成功提交

执行顺序:

1. 打开发布页
2. 如有旧草稿，先决定是否续写
3. 上传视频
4. 填写描述
5. 上传本地封面
6. 点击底部真实操作区里的 `发布`
7. 跳到 `作品管理`
8. 验证新条目状态

成功信号:

- `作品管理` 出现新条目
- 状态 `审核中`

### 5. 百家号

关键事实:

- 最近成功样本存在 `百度安全验证`
- 这是人工检查点，不是脚本失败
- 最终验证必须看 `作品管理 / 内容管理`

执行顺序:

1. 打开图文编辑后台
2. 先查 `作品管理`，确认同标题没重复
3. 填标题
4. 填正文
5. 上传本地横版封面
6. 提交
7. 如果出现 `百度安全验证`，人工完成后立即继续
8. 回 `作品管理 / 内容管理`

成功信号:

- `提交成功，正在审核中...`
- 或 `作品管理` 里直接出现 `已发布`

### 6. 今日头条 / 头条号

本地稳定规则:

- 入口走 `主页 -> 创作 -> 图文`
- 缺登录态时会卡短信验证码登录页
- `预览并发布` 后还要点一次 `确认发布`
- `审核中` 算成功提交

执行顺序:

1. 进入创作者后台
2. 打开 `主页 -> 创作 -> 图文`
3. 如卡登录/短信验证码，先人工过检查点
4. 真实输入标题和正文
5. 上传本地横版封面
   - 本地验证里第一张图片输入更稳定
6. 点击 `预览并发布`
7. 再点 `确认发布`
8. 回 `作品管理`

成功信号:

- `作品管理` 出现新条目
- 状态 `审核中`
- 如有 `首发` 标识也一并记录

### 7. 知乎

关键事实:

- 富文本验证很吃真实编辑动作
- `发布` 按钮灰着时，通常不是没写进去，而是编辑器没被真正激活

执行顺序:

1. 打开知乎文章或回答编辑器
2. 填标题
3. 填正文
4. 如果 `发布` 仍然不可点:
   - 手动输入 1 个字
   - 再删掉
   - 重新检查发布按钮
5. 发布
6. 验证公开文章页

成功信号:

- visible `发布成功`
- 或直接进入公开页

### 8. 小红书

关键事实:

- 登录态丢失时会跳登录
- API 层可能返回 `-9136`
- `笔记管理` 列表可能有延迟
- 真正发布按钮节点要点对，不能点 wrapper

执行顺序:

1. 打开创作页
2. 确认没有跳登录
3. 上传视频或图文素材
4. 填标题
5. 填正文
6. 进入封面编辑
   - 本地稳定路径是先触发 cover block 的 hover operator
   - 等看到 `上传图片`
   - 再上传本地封面
7. 点击真实发布按钮
8. 检查返回结果和 `笔记管理`

成功信号:

- 请求返回 `success: true`
- 同时出现 `share_link`
- 或 `笔记管理` 出现新条目 `审核中`

## 飞书推送规则

每个平台到达已验证状态后，马上推飞书，不等整批结束。

建议消息字段:

- platform
- title / asset id
- verified state
- verification time
- publish url / management url

## 一定要落日志的字段

每个平台至少记录:

- 开始时间
- 完成时间
- 发布方式
- 最终状态
- 页面校验方式
- 阻塞文本
- 是否要重试
- 实际使用的素材路径
- 后续动作
