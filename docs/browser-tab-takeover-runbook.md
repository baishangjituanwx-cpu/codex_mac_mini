# 浏览器接管现有标签页执行手册

这份手册专门回答一个问题:

如果不是从空白新开页面开始，而是要“直接接管已经开着的标签页、半成品页、旧草稿页、失败后停住的页”，到底该怎么做。

## 先说结论

当前打包目录里，原本的 [`browser-operation-sop.md`](./browser-operation-sop.md) 已经覆盖了平台级发布流程。  
但如果你要求细到“直接接管现有标签页”，那必须额外看这份手册。

## 通用接管步骤

不管哪个平台，先按这个顺序判断。

### 第 1 步：先不要动页面，先做识别

先识别这 5 件事:

1. 当前 URL 是什么
2. 这是登录页、管理页、发布页，还是封面弹窗页
3. 页面上是否已经有上传过的视频 / 图片
4. 标题、描述、正文是不是已经有值
5. 这个值是不是当前这次要发的内容，而不是昨天残留的旧草稿

### 第 2 步：先看管理页，不先点发布

如果平台存在管理页、作品页、视频管理页、笔记管理页，先去看它。

目的只有一个:

确认同标题、同视频、同描述片段、同时间段的内容是不是已经存在。

如果已经存在:

- 不要继续在当前草稿页点发布
- 先判断是“已成功、待审核、需编辑”，还是“真的没发出去”

### 第 3 步：把当前标签页归类

只分成 4 类:

1. 可继续的半成品页
   - 素材还在
   - 当前字段就是本次目标内容
2. 错草稿页
   - URL 对，但内容不是这次的
3. 假登录页 / 失效页
   - 看起来在后台，实际已经跳登录或权限失效
4. 已完成页
   - 已有成功信号，只差最终验证

### 第 4 步：只在“可继续的半成品页”上续作

满足下面 3 个条件才允许直接续作:

1. 当前页面的素材就是这次目标素材
2. 当前字段内容能和发布包对上
3. 管理页还没有同内容成功记录

否则就不要硬接。

### 第 5 步：续作时必须重读关键字段

不要因为页面上“看起来有值”就信它。

续作时最少重读:

- 标题
- 描述 / 正文
- 封面
- 上传状态

### 第 6 步：发布后不要立刻关页

现有标签页续作比空白页更容易出现“视觉成功、实际失败”。

所以发布后必须再验证一次:

- 管理页出现新条目
- 公开页可见
- 或返回数据明确成功

### 第 7 步：能停就停，不要为了自动化强行重发

最危险的错误不是“没发出去”，而是“重复发出去”。

## 1. 微信视频号

这是接管现有标签页时最复杂的平台。

### 已验证事实

- 真实发布表单在 `iframe[name="content"]`
- 多个 `post/create` 标签页可以同时开着，而且 URL 完全一样
- 同一个 URL 下可能是不同草稿状态
- create 页显示 `已发表` 时，顶层 URL 可能还不变
- 如果页面已经有视频、短标题、描述，不代表这三个值真的绑定到最终发布状态

### 接管已有标签页时的判断顺序

1. 先看当前是否在:
   - `login.html`
   - `platform/post/create`
   - `micro/content/post/list`
2. 如果在 `post/create`:
   - 不先发
   - 先进 frame 读页面内容
3. 读这 4 个核心信号:
   - 是否已有上传视频
   - `视频描述` 是否有值
   - `短标题` 是否有值
   - 3:4 封面是否已经是这次要用的图
4. 再去 `视频管理` 列表查:
   - 同视频
   - 同描述片段
   - 近期同时间条目

### 哪种标签页可以直接接管

只允许接管这两种:

1. 半成品 ready 页
   - 视频已上传
   - 描述已填
   - 短标题已填
   - 还没点发表
2. 删除错误成品后的修复页
   - 旧视频还挂在当前 create 页
   - 你确认这是刚才那次要修复的同一条

### 哪种标签页必须放弃

下面任一条成立，就不要继续点 `发表`:

1. `视频管理` 已经有同视频
2. 这个 create 页里的内容和这次发布包不一致
3. create 页跳到 `login.html`
4. 页面残留旧草稿但你无法确认是哪一条
5. 当前 visible UI 和 frame 里的真实状态对不上

### 现有标签页续作的稳定顺序

#### 情况 A：已有视频、描述、短标题，只差封面或发表

1. 先确认 `视频管理` 没有同视频
2. 在当前 create 页里重新读:
   - 描述
   - 短标题
3. 如果任一字段空了，必须重新真实输入
4. 点击封面区域里的 `编辑`
5. 如弹出 `编辑封面`，优先走本地封面上传
6. 本地验证里，稳定路径通常是:
   - 找第二个 `input[type="file"]`
   - 上传本地 3:4 封面
   - 点击可用的真实 `确定`
7. 等待上传相关文案完全消失:
   - `文件上传中，请等待完成后再发表。`
   - `0%`
   - `取消上传`
8. 再次确认描述和短标题仍然正确
9. 点击 `发表`
10. 不以 create 页 toast 为最终成功，继续去列表页查

#### 情况 B：页面已经弹 toast `已发表`

不要立即收工。

继续做:

1. 截图当前 create 页
2. 确认封面视觉上真的是这次要的封面
3. 再去 `micro/content/post/list`
4. 查新行是否存在
5. 查右侧描述片段是否正确

### 视频号的硬停止条件

- `same video do not republish`

只要 `视频管理` 里已经有同视频，就停。

## 2. 快手

### 已验证事实

- 草稿续写是可行路径
- 页面提示 `还有上次未发布的视频，是否继续编辑？` 时，优先续作
- `作品管理` 是最终真相源
- `审核中` 就算提交成功

### 接管已有标签页时先看什么

1. 当前是不是发布页
2. 页面顶部有没有 `继续编辑`
3. 当前视频是不是这次目标视频
4. 当前描述是不是这次内容
5. 再去 `作品管理` 查同 duration + 同描述

### 可以直接接管的页

1. 顶部明确提示 `继续编辑` 的草稿页
2. 视频已上传、描述已填，但还没最终提交的页

### 接管顺序

1. 先看 `作品管理`
2. 没有重复，再回当前草稿页
3. 如果有 `继续编辑`，先点它
4. 重读描述编辑器 `#work-description-edit`
5. 检查封面是不是已经换成 prepared cover
6. 如果没有，走:
   - `上传新封面 / 上传封面 / 更换封面`
   - 写入本地封面
   - 确认预览真的变了
7. 点击底部真实操作区 `发布`
8. 回 `作品管理`

### 必须停止的情况

1. `作品管理` 已经有同描述、同时长的新条目
2. 当前页看起来是草稿，但你不能确认视频是不是同一个
3. 顶部提示的是旧草稿，而发布包已经换主题

## 3. 小红书

### 已验证事实

- 登录态可能在打开创作页时直接失效
- UI 看起来能发，不代表 API 能过
- 最强成功信号是:
  - `success: true`
  - `share_link`
  - `笔记管理` 出现 `审核中`

### 接管已有标签页时怎么判断

1. 先确认没被重定向到登录
2. 再确认当前页面上的素材是不是这次的
3. 再确认标题和正文是否和发布包一致
4. 最后再去 `笔记管理`

### 可以接管的页

1. 视频 / 图片已经上传完成
2. 标题、正文还在
3. 只是封面没改或还没点发布

### 接管顺序

1. 先去 `笔记管理` 查是否已经存在同内容
2. 如果没有，再回当前编辑页
3. 重读标题
4. 重读正文
5. 如需改封面，不要直接点静态文案 `修改封面`
6. 稳定路径是:
   - 触发 cover block 的 hover operator
   - 等真实弹层出现 `上传图片`
   - 再上传本地封面
7. 点击真实发布按钮，不点 wrapper
8. 提交后先记返回结果
9. 再查 `笔记管理`

### 必须停止的情况

1. 返回 `-9136`
2. 页面已失登录态
3. `笔记管理` 里已经出现同条内容

## 4. 抖音

### 已验证事实

- 标题字段是独立必填项
- 光看描述和红色发布按钮不够
- 发布页可能留在原 URL，但提交可能不完整
- 管理页是最终核验页

### 接管已有标签页时先做什么

1. 不先信当前标题
2. 先去 `作品管理` 查最近两条
3. 看时间、描述、缩略图是不是已经有这次内容

### 可以接管的页

1. 视频已上传
2. 标题页还在
3. 描述已填
4. 当前不是旧主题残留

### 接管顺序

1. 先查 `作品管理`
2. 没有重复再回发布页
3. 真实点击标题输入框
4. 重打标题，或至少重读后再补打
5. 重读描述
6. 如封面没配好，重新进 `设置封面`
7. 优先本地 prepared cover，而不是 AI 封面
8. 封面保存后重新看外层预览是否已切换到目标封面
9. 点击发布
10. 回 `作品管理` 核验

### 必须停止的情况

1. 管理页已经有同描述、同时间的新条目
2. 当前标签页是昨天旧草稿
3. 标题字段无法确认真实值

## 5. 百家号

### 已验证事实

- 最终验证不能看首页卡片，要看 `作品管理 / 内容管理`
- 重复同标题重试会制造假失败
- 可能卡 `百度安全验证`

### 接管已有标签页时的规则

1. 如果当前是编辑页，不先继续填
2. 先开 `作品管理`
3. 搜同标题
4. 如果同标题已在:
   - `已发布`
   - `审核中`
   - `审核未通过`
   就不要把当前页当成“空白失败页”继续提

### 可以接管的页

1. 标题和正文就是当前这次文章
2. 管理页还没有同标题记录
3. 当前只是卡在安全验证前后

### 接管顺序

1. 查 `作品管理`
2. 没重复再回编辑页
3. 重读标题
4. 重读正文
5. 确认题图还是本地封面
6. 提交
7. 若出现 `百度安全验证`，人工过后立刻继续当前页
8. 回 `作品管理 / 内容管理`

### 必须停止的情况

1. 同标题已存在
2. 当前页内容和发布包不一致
3. 第二次补发只是因为你没去管理页查

## 6. 今日头条 / 头条号

### 已验证事实

- 缺创作者登录态时，会留在验证码登录页
- 这是会话问题，不是 broken draft
- 提交链路是:
  - `预览并发布`
  - `确认发布`
- `审核中` 算成功提交

### 接管已有标签页时怎么做

1. 先看当前是编辑页还是登录页
2. 如果是验证码登录页:
   - 不要继续调编辑器
   - 先把它归类成会话失效
3. 先去 `作品管理`
4. 查同标题是否已经在审核中或已发

### 可以接管的页

1. 当前还在图文编辑器
2. 标题、正文是本次内容
3. 封面还是这次封面
4. 管理页没有同标题新记录

### 接管顺序

1. 查 `作品管理`
2. 没重复再回当前编辑页
3. 重读标题
4. 重读正文
5. 确认封面输入仍有效
6. 点击 `预览并发布`
7. 再点 `确认发布`
8. 回 `作品管理`

### 必须停止的情况

1. 停在验证码登录页
2. 管理页已经有同标题新行
3. 当前页是旧文章草稿，不是本次文章

## 7. 知乎

### 已验证事实

- 最大问题是编辑器激活，不是字段缺失
- 半成品页是可以接管的
- 关键是重新触发真实编辑动作

### 接管已有标签页时怎么判断

1. 标题是不是这次标题
2. 正文是不是这次正文
3. 发布按钮为什么不可用

### 可以接管的页

1. 标题和正文就是当前文章
2. 只是 `发布` 灰着

### 接管顺序

1. 先确认当前文不是旧草稿
2. 重新聚焦正文区
3. 人工输入一个字
4. 再删掉
5. 观察 `发布` 是否解锁
6. 再发布
7. 跳公开页验证

### 必须停止的情况

1. 页面内容和发布包已经不一致
2. 登录状态失效
3. 你不确定当前编辑器是不是对应这篇文章

## 8. 微博

微博这边“接管已有标签页”的本地证据没有视频号那么复杂，但可以按保守规则处理。

### 保守接管规则

1. 先看当前编辑器里的视频是不是本次视频
2. 再看正文是不是本次正文
3. 再去主页流 / 管理入口确认没有同条已发

### 可以接管的页

1. 视频已挂载
2. 正文已填
3. 还没提交

### 接管顺序

1. 查最近发布结果
2. 没重复，再回当前编辑器
3. 重读正文第一屏
4. 确认前几秒视频与正文一致
5. 提交
6. 回主页流验证

### 必须停止的情况

1. 主页流已经有同条
2. 当前页视频不是这次视频
3. 当前正文是旧主题残留

## 最后的落地建议

如果你要把这套东西长期复制，真正该记住的不是“点哪里”，而是每个平台的三件事:

1. 哪个页面才是真相源
2. 哪种半成品页可以续作
3. 哪种情况下必须停止，避免重复发布

这份手册就是按这三件事写的。
