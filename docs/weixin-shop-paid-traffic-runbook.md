## 操作门

默认只读。任何写操作都必须先展示任务 ID、商品 ID、调整前值、调整后值和生效方式，并取得本轮明确确认。提交后必须从任务详情、任务列表和操作日志回读；ROI、预算、素材、文案、开关及暂停/恢复分别确认。

总日预算只有一个输入框。创建最低预算与后续修改幅度不是同一个规则，每次以页面当时提示为准，不把 `50` 或 `55` 写成永久阈值，也不填写 `15/9/6` 等拆分预算。

## 投流成本口径

普通推广 10% 属于独立 CPS 渠道。小店投放默认采用 `PAID_TRAFFIC_ONLY`，不得把 CPS 佣金重复计入。只有官方证据证明同一归因订单叠加承担 CPS 佣金时，才使用 `STACKED_VERIFIED`。

```text
投流前贡献毛利 = 售价 * (1 - 平台费率 - 支付费率 - 售后准备金率)
                  - 实时成本 - 卖家运费 - 其它固定成本
贡献毛利率 = 投流前贡献毛利 / 售价
保本ROI = 1 / 贡献毛利率
实际成交ROI = 归因GMV / 消耗
投流后贡献毛利 = 归因GMV * 贡献毛利率 - 消耗
```

## 复盘规则

- 素材审核中：等待，不评价 ROI。
- 曝光大于 0、消耗为 0：继续观察。
- 曝光为 0：先查素材、开关、资格和限制。
- 已消耗无订单：按当前可承受 CPA 提出建议，不自动暂停。
- 有订单且实际 ROI 低于保本 ROI：提出暂停建议。
- 实际 ROI 在保本 ROI 与目标 ROI 之间：保持预算。
- 实际 ROI 达标且贡献毛利为正：至少形成稳定支付订单后再讨论放量。

`小店投放数据`按“任务 × 商品 × 日期 × 检查点”追加。20:30 后第一轮回查只读，历史行不覆盖，原始值不估算。
