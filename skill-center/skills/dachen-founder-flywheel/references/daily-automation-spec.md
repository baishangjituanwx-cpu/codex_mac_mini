# 每日自动化任务说明

## 自动化目标

把“发布 / 评论私信互动 / 复盘 / 优化 / 执行”拆成 3 段固定日程。

## 一、早间任务

### 目标

- 读取昨天数据
- 选今天主话题
- 产出 8 平台发布优先级

### 输出

- 今日主话题
- 每个平台的包装重点
- 哪些平台该先发
- 哪些封面、标题要先改

## 二、午间任务

### 目标

- 扫评论和私信
- 给出回复优先级
- 抓高价值 objections

### 输出

- 今日评论回复队列
- 今日私信线索
- 明天可继续放大的问题

## 三、晚间任务

### 目标

- 汇总 8 平台反馈
- 判断 keep / cut / retest
- 写出明天优化动作

### 输出

- 今日平台胜负手
- 明天继续做什么
- 明天停止什么
- 明天复测什么

## 运行规则

- Morning focuses on topic and publish.
- Midday focuses on interaction.
- Evening focuses on review and optimization.
- If a new reusable lesson appears, update memory.
- If a browser action is blocked by login or platform risk control, report the checkpoint instead of pretending the task completed.
