# 大陈 AI 创业者 IP 八平台飞轮方案

## 核心目标

围绕 `智能体应用` 主题，把大陈建立成：

- 有判断的 AI 创业者
- 不空谈模型、只讲可执行应用的人
- 能把“智能体应用”讲成真实工作问题的人

## 飞轮定义

飞轮不是“每天发一点”。

飞轮是：

1. 选一个核心话题
2. 按平台改写包装
3. 发出
4. 收评论和私信
5. 复盘
6. 把结论反推回明天的话题、封面、标题、脚本

## 一、发布

### 统一主线

每天只打一个主话题，例子：

- 为什么很多团队用了 AI，返工却没有减少
- 为什么智能体应用比聊天工具更接近真实工作
- AI 从会说到会做，中间差的到底是什么

### 平台分工

- 微博：一句判断 + 早期互动
- 百家号：问题型标题 + 搜索需求
- 知乎：论证型长文 + 信任建设
- 头条号：业务问题 + feed 点击
- 抖音：3 秒痛点 + 演示或态度
- 小红书：原生卡面 + 场景化表达
- 视频号：信任感 + 转发和私域延展
- 快手：直接、朴素、可理解的演示

### 当天执行顺序

1. 先定一个核心话题
2. 先做封面和 hook
3. 先发短内容平台
4. 再发长文平台
5. 最后补齐快手

## 二、评论与私信互动

### 评论要解决的不是“回复率”，而是“下一轮选题”

重点收集：

- 用户到底没听懂哪一步
- 用户最想知道的使用场景是什么
- 用户为什么不信
- 用户问的是产品，还是在问市场判断

### 互动分层

- 第一层：高价值评论
- 直接回，越快越好
- 第二层：重复问题
- 回一次后沉淀成下一轮内容
- 第三层：低价值争论
- 不耗时间
- 第四层：私信意向
- 单独记录为潜在线索

## 三、复盘

### 每晚必看 4 件事

1. 哪个平台先起量
2. 哪种表达最容易让人停住
3. 哪些评论是高价值问题
4. 失败是因为内容、包装、还是账号状态

### 复盘结论必须落到 3 类动作

- 明天继续放大的东西
- 明天停止的东西
- 明天要复测的变量

## 四、优化

优化顺序固定：

1. 选题
2. hook
3. 封面
4. 标题
5. 结构
6. CTA

不要反过来。

如果平台有展现没点击，先看封面和标题。
如果有点击没互动，先看内容结构。
如果所有内容都弱，再回到账号定位和平台匹配。

## 五、执行

### 每天必须有 3 个输出

- 一个主话题
- 一组平台化包装
- 一份复盘结论

### 每周必须有 3 个沉淀

- 高价值评论清单
- 高表现封面与标题清单
- 失败样本清单

## 六、平台差异化动作

### 微博

- 目标：观点传播和评论样本
- 动作：用判断句，不要写介绍文

### 百家号

- 目标：问题搜索和长尾分发
- 动作：标题必须像问题

### 知乎

- 目标：建立专业可信的人设
- 动作：多论证、少空话

### 头条号

- 目标：用 feed 测 click-through
- 动作：有展现没点击，优先换封面和标题

### 抖音

- 目标：用短视频测最强 hook
- 动作：3 秒定生死

### 小红书

- 目标：让智能体应用议题变成“可收藏的经验”
- 动作：像笔记，不像广告

### 视频号

- 目标：强化 founder trust
- 动作：口吻更稳，结论更可信

### 快手

- 目标：拉低理解门槛
- 动作：更直接、更朴素
