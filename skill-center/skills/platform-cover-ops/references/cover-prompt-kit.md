# 封面提示词与布局模板

这个文件提供第三层可执行模板。

前两层解决的是：
- 哪个平台该怎么改
- 哪种内容该套哪类结构

这一层解决的是：
- 怎么把它直接写成 AI 出图 prompt
- 怎么把它直接交给设计师
- 怎么快速确定字位、主体位和配色方向

## 一、统一变量

每次写 prompt 前，先把这 6 个变量写出来：

- `平台`
- `内容类型`
- `核心冲突`
- `主体`
- `结果暗示`
- `禁用元素`

示例：
- 平台：抖音
- 内容类型：营销内容
- 核心冲突：用了 AI 还在返工
- 主体：一个疲惫的营销经理 + 屏幕上的内容稿
- 结果暗示：流程断裂、反复修改
- 禁用元素：科幻蓝光、机械手臂、悬浮芯片、密集小字

## 二、统一出图 Prompt 骨架

### 通用主 Prompt

```text
为{平台}制作一张{内容类型}封面，主题是“{核心冲突}”。
主体是{主体}，画面必须先让用户一眼看懂问题，再看懂结果暗示“{结果暗示}”。
画面风格真实、克制、可点击，不要像品牌广告海报。
构图保持单主体或双主体，不做复杂拼贴。
核心信息放在中心安全区，四周留出裁切空间。
文字区域只保留一句短文案，适合缩略图阅读。
```

### 通用负面 Prompt

```text
不要科幻蓝光，不要机械手臂，不要漂浮芯片，不要密集 UI 拼贴，不要多段小字，不要企业宣传海报，不要强 logo 墙，不要抽象科技背景，不要无关装饰。
```

## 三、四类内容的 Prompt 模板

### 1. AI 产品

#### AI 出图 Prompt

```text
为{平台}制作一张 AI 产品内容封面。
核心不是“模型很强”，而是“这个产品真的能解决具体问题”。
画面需要有真实使用场景、产品结果或工作流线索。
文案只强调一个差异点：{核心冲突}。
整体观感应当更像一个真实产品场景，而不是科幻概念图。
```

#### 设计师 Brief

- 主体：产品结果图、界面、人物使用场景三选一，不混太多元素。
- 字数：6 到 12 个汉字。
- 配色：中性背景 + 单一强调色。
- 禁止：科技感素材堆砌、伪 3D 芯片、过度未来风。

#### 推荐布局

- 上中部：一句判断
- 中部：主体或结果
- 下部：尽量留空

### 2. 营销内容

#### AI 出图 Prompt

```text
为{平台}制作一张营销内容封面，主题冲突是“{核心冲突}”。
画面要先传达压力、返工、成本、流程断裂或团队忙乱感。
主体必须贴近真实业务场景，比如改稿、开会、盯屏、反复修改。
封面一眼就能看懂“问题比解决方案更重要”。
```

#### 设计师 Brief

- 主体：真实团队场景、工作流场景、屏幕改稿场景。
- 文案：一句问题句。
- 配色：高反差，但不做夸张红黑警报风。
- 禁止：纯科技蓝背景、抽象地球、抽象数据流。

#### 推荐布局

- 上中部：问题句
- 中部：人物或冲突场景
- 底部：少放元素

### 3. 人物口播

#### AI 出图 Prompt

```text
为{平台}制作一张人物口播封面。
主体是一个正在直接表达观点的人，强调眼神、表情、态度。
文案像一句口语判断，不像广告标题。
让用户看到封面就想知道“这个人要说什么”。
```

#### 设计师 Brief

- 主体：人脸或半身，占画面 45% 以上。
- 文案：一句口语话。
- 配色：背景简洁，主体突出。
- 禁止：人太小、背景过满、文案盖脸。

#### 推荐布局

- 上中部：一句口语判断
- 中部：人物
- 右侧或左侧：留一点呼吸空间

### 4. 产品演示

#### AI 出图 Prompt

```text
为{平台}制作一张产品演示封面。
重点是让用户一眼知道“演示什么”和“看完能得到什么”。
画面优先使用结果截图、前后对比、操作结果，而不是纯人物情绪。
文案突出关键动作或关键差异：{核心冲突}。
```

#### 设计师 Brief

- 主体：结果界面、前后对比、单步操作结果。
- 文案：动作词 + 结果词。
- 配色：干净、清晰，不花。
- 禁止：满屏 UI、四宫格、看不清重点的流程拼接。

#### 推荐布局

- 上部：一句动作判断
- 中部：结果界面或对比
- 下部：留空，避免信息爆炸

## 四、平台修正参数

同样一张母版，不同平台至少做这些修正。

### 微博

- 文案更短
- 图文首图允许更轻字甚至无字
- 视频封面必须和正文第一句联动

### 百家号

- 问题型更强
- 封面尽量像“用户会搜的问题”
- 不要品牌口号感

### 知乎

- 证据感更强
- 字更少
- 截图、图表、流程图优先于营销海报

### 今日头条 / 头条号

- 问题更直接
- 场景更业务化
- 避免抽象科技图

### 抖音

- 文案更短更狠
- 人物或结果要更大
- 默认 AI 封面只是初稿，必须二改

### 小红书

- 更像原生笔记
- 字体别太像直播切片海报
- 真实生活感比设计感更重要

### 微信视频号

- 按 `3:4` 保守排版
- 重要信息更居中
- 必须检查分享卡片预览

### 快手

- 更直接、更朴素
- 字更大
- 情绪和动作比精致设计更重要

## 五、四套常用字位模板

### 模板 A：上字中人

- 适合：人物口播、营销内容
- 结构：
- 上中部一句短句
- 中部主体人物
- 下方留空

### 模板 B：上字中结果

- 适合：产品演示、AI 产品
- 结构：
- 上部一句判断
- 中部结果界面或结果图
- 四周留安全区

### 模板 C：左字右主体

- 适合：需要兼顾人物和对象
- 结构：
- 左侧短句
- 右侧人物或产品
- 只适合横向信息平衡较好的图

### 模板 D：无字强画面

- 适合：微博、知乎、某些小红书封面
- 结构：
- 不上大字
- 靠主体、表情、动作和标题联动来承担点击

## 六、最实用的 12 条封面短句

- `不是更会说 是更会做`
- `用了AI 为什么还返工`
- `AI做了 你还得重做`
- `团队用了AI 为何更忙`
- `问题不在生成 在流程`
- `这一步不改 AI白上了`
- `很多团队把AI用反了`
- `这不是聊天工具 是工作入口`
- `从会说到会做 差在哪`
- `这个演示 值钱在后面`
- `看完就懂 差哪一步`
- `AI写完了 为什么还得改`

## 七、自动出图时的最小执行顺序

1. 先选内容类型模板。
2. 再套平台修正参数。
3. 先出 `无字版` 和 `短句版` 各一张。
4. 再缩略图预览。
5. 最后才进平台编辑器选帧或上传 cover。

如果平台编辑器本身支持：
- AI 默认封面
- 自定义封面
- 首帧重选

也不要跳过第 3 步。先有母版，再去平台里做轻编辑。
