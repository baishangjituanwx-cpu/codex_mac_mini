# SCM 全部商品永久删除

这是高风险、不可逆操作。只有用户在当前任务中明确确认“永久删除”及精确范围后才能执行；默认只做预览和计数。

## 执行流程

1. 先确认处于“全部商品”范围，读取页面警示文字，核对商品清单或确定性筛选条件、预计总数和每页数量。
2. 执行前再次向用户确认永久删除范围；筛选条件模糊、相似商品较多或总数异常时停止。
3. 将分页设为每页 100 件（若页面允许），逐批核对当前页商品与目标范围，确认表头复选框确实选中当前页后提交删除。
4. 等待异步回写，再用相同筛选条件重新提交；只有总数减少到预期或最终为 0 条/暂无数据才完成该批。
5. 对指定商品清单，必须按商品名称、型号和包装规格逐一重新检索；聚合数量卡和确认框关闭都不能替代逐项核验。

## 停止条件

- 页面提示是“从分组移除”而非永久删除时，转交 scm-group-bulk-remove。
- 出现“表格为空但总数未变”、重复提交风险、异步状态不明或筛选结果漂移时暂停，不继续下一批。
- 不删除账号、凭据、代码、日志或非目标商品；不输出账号、密码、Cookie、Token、密钥。

## Windows Repo Mirror Notes

本技能是 SCM 浏览器控制流程，不需要独立的 PowerShell 或 `.cmd` 业务启动器。Windows 上复用 Codex 的共享浏览器控制能力和同一套页面回读/异步核验规则，不要把永久删除改写成临时 PowerShell、`curl` 或本地 API 包装器。

Windows 路径与快捷键规则：

- 技能安装位置通常为 `%USERPROFILE%\\.codex\\skills\\scm-all-products-permanent-delete\\`；
- 截图、清单和脱敏证据使用带引号的 `C:/Users/<name>/...` 绝对路径，不把 `/Users/...` 写入记录；共享资料使用带引号的 UNC 或映射盘路径；
- 浏览器 `press_key` 使用 `Control+R`/`F5`、`Control+L`、`Control+A`、`Alt+Left` 和 `Alt+Right`，不要照搬 Mac 的 `Meta` 键。

任何删除提交仍需当前会话中的明确授权、精确范围和逐批回读；不要把 Cookie、Token、密钥或原始请求头放入 Windows 文件、任务参数或环境变量。
