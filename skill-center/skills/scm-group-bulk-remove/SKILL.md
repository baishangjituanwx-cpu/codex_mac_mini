# SCM 分组批量移除

适用于“我的选品库/全部商品”中的当前分组清理。它只把商品移出所选分组，不删除全局商品库。

## 执行流程

1. 要求用户明确当前分组、商品状态或协议价筛选条件和处理范围；点击提交并记录初始总数。
2. 在“全部商品”对话框核对当前分组和筛选条件，使用表头复选框选择当前页（通常每页最多 100 件）。
3. 点击“批量移除”，在确认框中确认“从此分组中移除”。
4. 等待异步回写后，用相同筛选条件重新提交查询；只有总数按预期减少或显示“共 0 条/暂无数据”才算完成。
5. 若表格暂时为空但总数未变，先等待并刷新，不要重复提交同一批。

## 安全边界

- 任何“永久删除”提示都必须停止并转交 scm-all-products-permanent-delete。
- 不以确认框关闭、短时列表变化或聚合卡变化作为最终证据。
- 每批记录筛选条件、提交前数量、刷新后数量和异常状态；不得输出凭据。

## Windows Repo Mirror Notes

本技能是 SCM 浏览器控制流程，不需要独立的 PowerShell 或 `.cmd` 业务启动器。Windows 上复用 Codex 的共享浏览器控制能力和同一套异步刷新/结果回读规则，不要用临时 PowerShell、`curl` 或本地 API 包装器替代页面确认。

Windows 路径与快捷键规则：

- 技能安装位置通常为 `%USERPROFILE%\\.codex\\skills\\scm-group-bulk-remove\\`；
- 截图、批次记录和导出证据使用带引号的 `C:/Users/<name>/...` 绝对路径；共享资料使用带引号的 UNC 或映射盘路径；
- 浏览器 `press_key` 使用 `Control+R`/`F5`、`Control+L`、`Control+A`、`Alt+Left` 和 `Alt+Right`，不要照搬 Mac 的 `Meta` 键。

移除提交仍需当前会话中的明确分组和范围确认；不要把 Cookie、Token、密钥或原始请求头写入 Windows 文件、任务参数或环境变量。
