# SCM 主页批量选品

适用于 scm.smallemon.com/pxh/ 的主页列表操作。默认使用浏览器控制能力；只在用户明确给出筛选条件、目标分组和目标数量后执行会改变选品状态的点击。

## 执行流程

1. 确认处于选品主页，记录来源平台、价格区间、商品保障、目标分组和目标数量；筛选条件变化后等待列表稳定。
2. 每页使用页面级“全选页面商品”控件（实际页面中通常是 button.all-choice），不要只点击卡片内层文字。
3. 打开“已选商品”，核对当前批次数量。单批最多处理 30 件；若只需补足剩余数量，只保留所需商品并取消其余勾选。
4. 点击“加入选品库”，选择目标分组并确认；等待“操作成功”或等价成功提示。
5. 关闭或刷新“已选商品”后再进入下一页，记录每页新增数，避免旧批次残留或重复提交。
6. 最后重新打开抽屉和目标分组核验结果。仅以逐批数量、成功回执和刷新后的列表为依据；分组计数卡只作为最后观察值。

## 安全边界

- 本 Skill 只负责新增选品和分组，不执行“批量移除”“永久删除”、商品源刷新或数据库修改。
- 单批超过 30 件时先拆批，不重复点击未完成的异步请求。
- 页面空白、总数未刷新、弹窗仍在处理或成功提示不明确时暂停并报告，不把点击完成当作成功。
- 报告中不得输出账号、密码、Cookie、Token、密钥或私人资料。

## Windows Repo Mirror Notes

本技能是 SCM 浏览器控制流程，不需要独立的 PowerShell 或 `.cmd` 业务启动器。Windows 上复用 Codex 的共享浏览器控制能力、当前登录会话和逐页回读规则，不要把批量选品改写成临时 PowerShell、`curl` 或本地 API 包装器。

Windows 路径与快捷键规则：

- 技能安装位置通常为 `%USERPROFILE%\\.codex\\skills\\scm-homepage-batch-select\\`；
- 截图、批次记录和导出证据使用带引号的 `C:/Users/<name>/...` 绝对路径；共享资料使用带引号的 UNC 或映射盘路径；
- 浏览器 `press_key` 使用 `Control+R`/`F5`、`Control+L`、`Control+A`、`Alt+Left` 和 `Alt+Right`，不要照搬 Mac 的 `Meta` 键。

加入选品仍需当前会话中的明确筛选条件、目标分组和目标数量；不要把 Cookie、Token、密钥或原始请求头写入 Windows 文件、任务参数或环境变量。
