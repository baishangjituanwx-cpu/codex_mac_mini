# 提示词9：字幕白名单硬规则

## 用户原始要求

第三次补充要求：

字幕白名单，模型只能显示和人物台词完全一致的字幕，不得自创、改写、增删、同义替换或显示其他文字。

早前要求：

【字幕白名单，模型只能显示下面4句，不得自创、改写、增删、同义替换或显示其他文字】

0-3秒字幕，必须和【人物A】台词一致:【短台词1】

3-6秒字幕，必须和【人物B】台词一致:【短台词2】

6-10秒字幕，必须和【人物C】台词一致:【短台词3】

10-15秒字幕，必须和【人物A】台词一致:【短台词4】

## 规范化使用模板

字幕白名单硬规则：模型只能在画面字幕位置显示和人物台词完全一致的字幕。字幕白名单只有下面4句。不得自创、改写、增删、同义替换、拆分、合并、重复或显示其他文字。人物口播也只能逐字朗读对应台词，不能添加语气词、解释句、品牌长名、地址、促销语或总结语。

0-3秒：【人物A】口播必须逐字说：【短台词1】；画面字幕必须逐字显示：【短台词1】。

3-6秒：【人物B】口播必须逐字说：【短台词2】；画面字幕必须逐字显示：【短台词2】。

6-10秒：【人物C】口播必须逐字说：【短台词3】；画面字幕必须逐字显示：【短台词3】。

10-15秒：【人物A】口播必须逐字说：【短台词4】；画面字幕必须逐字显示：【短台词4】。

全片字幕白名单只有这4句：

1. 【短台词1】
2. 【短台词2】
3. 【短台词3】
4. 【短台词4】

如果画面出现白名单以外的任何字幕，或字幕与人物台词不完全一致，或出现乱码、重复字幕、同义改写字幕、额外解释文字，本条视频判定为不合格，不能进入最终成品。

## 后续执行规则

- 后续 Seedance 生成提示词必须优先采用该白名单段落。
- 优先使用 4 句短台词，减少模型漂移概率。
- 每句建议控制在 3-6 个汉字，最长不超过 8 个汉字。
- 不再把地址、品牌全名、活动文案放进画面字幕白名单。
- 该规则属于 prompt 级约束，不等同于 API 结构化字幕轨保证；生成后仍必须抽帧验收。
