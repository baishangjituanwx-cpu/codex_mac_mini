# 提示词10：对白与字幕硬要求

## 用户原始要求

【对白与字幕硬要求】

全片中文普通话对白，真实办公室同期声质感，口型自然同步。字幕必须由模型直接生成在视频画面中，禁止后期字幕条风格。字幕显示必须跟人物实际说话内容逐字一致，不多显示、不少显示、不提前显示、不滞后显示。字幕不要出现错字、乱码、少显示；字幕不要严重多行、长字幕堆叠，不要遮挡人物表情。字幕必须是单行白字、透明底、允许极细黑描边，固定在画面下方安全区，不能有黑色或灰色背景条。

## 规范化使用模板

对白与字幕硬要求：全片必须是中文普通话对白，真实同期声质感，人物口型自然同步。字幕必须由模型直接生成在视频画面中，禁止生成后期字幕条风格。

字幕同步要求：字幕必须跟人物实际说话内容逐字一致，不多显示、不少显示、不提前显示、不滞后显示。人物没说出口的文字不能出现在字幕里；字幕里出现的每个字都必须来自当前人物正在说的台词。

字幕质量要求：字幕不要出现错字、乱码、漏字、少显示、同义改写、重复显示、额外解释文字。不要严重多行，不要长字幕堆叠，不要遮挡人物表情和嘴型。

字幕样式要求：字幕必须是单行白字、透明底，允许极细黑描边；固定在画面下方安全区。不能有黑色背景条、灰色背景条、半透明色块或大面积字幕底框。

失败判定：如果字幕与口播不逐字一致，或出现错字、乱码、额外字幕、黑底字幕条、严重多行堆叠、提前/滞后显示，本条视频判定为不合格，不能进入最终成品。

## 后续执行规则

- 先定义字幕白名单，再定义本条对白与字幕硬要求。
- 每次生成后必须抽帧验收字幕内容、字幕样式和显示时序。
