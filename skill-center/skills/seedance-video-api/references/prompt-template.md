# Seedance 15s Prompt Package Standard

适用场景：本工作区内通过 `seedance-video-api` 生成单条 Seedance 短视频时的默认提示词输出  
当前版本：`2026-04-18`

## 使用规则

当任务是“给 Seedance 出提示词”“整理成可直接提交的 Seedance payload”“补封面主标题和副标题”时，默认使用本模板。

默认输出顺序：

1. `生成模式`
2. `时长`
3. `比例`
4. `分辨率`
5. `视频主提示词`
6. `封面主标题`
7. `封面副标题`
8. `可直接提交的 JSON payload`

## 固定规则

- 单条 Seedance 任务默认按 `15秒` 生成
- 除非用户明确要求其他比例，默认按 `9:16`
- 分辨率默认按 `720p`
- 先判断是 `文生视频` 还是 `图生视频`
- 如果提供了真人素材，默认优先按 `图生视频`
- 只要使用真人素材，默认启用“严格保真人”规则
- 对 `智者大陈 / 百亿联盟陈永俊` 这条 founder-office 视频线，默认按 `3秒钩子 -> 剧情反转 -> 情绪共鸣 -> AI员工分工落地`
- 视频生成完成后，默认还要继续准备封面包

如果用户想要 `15秒以上`：

- 不要伪装成一个单任务
- 改成“多段生成 + 后续拼接”的方案

## 字幕硬规则

如果这条视频需要字幕，默认按当前工作区的硬规则处理：

- 字幕必须由模型直接生成在视频里
- 单行中文字幕
- 白字
- 透明底
- 无黑底字幕条
- 每行尽量控制在 `8` 个汉字以内

禁止：

- 无字幕母片 + 本地后期补字幕
- 本地叠加字幕修错字
- 用大面积黑底遮罩盖掉原字幕

如果模型字幕出现错字、多行、黑底、乱码或遮挡：

- 加强提示词重新生成
- 不要后期修补后再发布

## 真人素材默认规则

只要使用真人素材，不把人物当成可自由改造的参考氛围图。

提示词里必须明确写出：

- 严格保持原有人物身份稳定
- 严格保持原有人物大型轮廓、面型结构、五官位置、眼神、肤色、眼镜、年龄感稳定
- 严格保持原有人物发型、服装款式、服装颜色、配饰稳定
- 严格保持原有人物体态、体型、身材比例、轮廓和整体气质稳定
- 不要换脸
- 不要改变服装
- 不要突然变成另一个长相、另一个年龄段、另一种体态或另一种风格人物
- 不要年轻化、美颜化、网红化、变装或多替身
- 不要随意修改原有人物的大型轮廓、面型结构、服装款式和身份识别特征

如果用户给的是老板、创始人、真人员工这类真实人物素材，默认优先保真人，不优先追求夸张动作或风格变化。

## 提示词写法

Seedance 主提示词不要写成散乱镜头堆砌。优先保持：

- 一个明确主角
- 一个明确场景
- 一条连续动作线
- 一个稳定镜头语言
- 一个清晰收尾画面

优先写进提示词的 6 个部分：

1. 主体是谁
2. 在什么场景
3. 正在做什么
4. 镜头怎么移动
5. 光线和气氛是什么
6. 最后停在什么状态

避免：

- 太多互相冲突的镜头切换
- 太多抽象商业名词
- 一条提示词里塞太多阶段和支线

## 文生视频模板

```text
主体是{{主体设定}}。场景在{{场景设定}}。人物/主体正在{{核心动作}}。镜头以{{镜头语言}}推进，画面保持{{风格气质}}，光线为{{光线设定}}。中段出现{{关键变化}}，结尾停在{{收尾画面}}。整体真实、稳定、连贯，不要杂乱跳切，不要变形脸，不要低清晰度。如需字幕，字幕必须由模型直接生成，保持单行白字、透明底、无黑底字幕条，不要错字，不要多行，不要乱码。
```

## 图生视频模板

```text
严格参考上传的真人素材，严格保持原有人物身份稳定，严格保持原有人物大型轮廓、面型结构、五官位置、眼神、肤色、眼镜、年龄感稳定，严格保持原有人物发型、服装款式、服装颜色、配饰稳定，严格保持原有人物体态、体型、身材比例和整体气质稳定。严格保持原有人物的身份识别度，不要把真人素材改造成另一个人。场景延续为{{场景设定}}，主体从参考素材自然进入{{核心动作}}。镜头以{{镜头语言}}推进，画面保持{{风格气质}}，光线为{{光线设定}}。中段出现{{关键变化}}，结尾停在{{收尾画面}}。整体动作自然、转场顺滑，不要换脸，不要改服装，不要改体态，不要年轻化，不要美颜化，不要网红化，不要变装，不要多替身，不要风格漂移，不要突然改背景，不要把人物做成泛化演员脸。如需字幕，字幕必须由模型直接生成，保持单行白字、透明底、无黑底字幕条，不要错字，不要多行，不要乱码。
```

## 封面文案规则

Seedance 在这个工作区默认要同时给两条封面文案：

- `封面主标题`：`6到10个中文字符`
- `封面副标题`：`4到8个中文字符`

写法要求：

- 主标题要短、重、能看懂结果或替代关系
- 副标题补动作、收益或老板视角利益
- 尽量带 `AI员工` 或非常接近的替代说法
- 不要写成空泛功能词

推荐方向：

- 主标题：`AI员工上岗了`
- 副标题：`自动跑平台`

- 主标题：`AI员工替你盯运营`
- 副标题：`老板先下班`

- 主标题：`AI员工接手内容`
- 副标题：`省下运营时间`

## JSON 模板

### 文生视频

```json
{
  "prompt": "{{视频主提示词}}",
  "duration": 15,
  "ratio": "9:16",
  "resolution": "720p",
  "generate_audio": true
}
```

### 图生视频

```json
{
  "prompt": "{{视频主提示词}}",
  "image_url": "{{图片URL或local路径}}",
  "duration": 15,
  "ratio": "9:16",
  "resolution": "720p",
  "generate_audio": true
}
```

## 生成后检查清单

- 这是不是单条 `15秒` 内能成立的内容
- 主提示词是不是只有一条主动作线
- 是否已经明确 `文生视频` 或 `图生视频`
- 如果用了真人素材，是否已经明确“严格保持大型轮廓、脸型、五官、服装、体型、比例稳定”
- 封面主标题是不是 `6到10字`
- 封面副标题是不是 `4到8字`
- 封面文案是不是和视频内容方向一致
- 如果用户要超过 `15秒`，是不是已经改成分段方案
