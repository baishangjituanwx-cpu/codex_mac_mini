# Real-Person Consistency Prompt Rules

适用场景：当 Seedance 任务使用真人图片、真人素材库 `asset://...`、老板 / 创始人 / 员工的人像图时使用。  
当前版本：`2026-04-21`

## 核心原则

真人素材不是“氛围参考”，而是“身份锁定参考”。

只要输入是可识别的真人，提示词就要默认优先保护：

- 人物身份
- 大型轮廓
- 面型结构
- 五官位置与眼神
- 五官识别度
- 体型和比例
- 体态
- 发型
- 服装和配饰
- 整体年龄感与气质

## 必加约束

提示词里至少要明确这些意思：

- 严格保持原有人物身份稳定
- 严格保持原有人物大型轮廓、面型结构、五官位置、眼神、体型和体态稳定
- 严格保持原有人物发型、服装款式、服装颜色、配饰、年龄感和整体气质稳定
- 保持人物真实可识别，不要泛化成另一个演员
- 不要换脸
- 不要改服装
- 不要改体态
- 不要改年龄感
- 不要年轻化
- 不要美颜化
- 不要网红化
- 不要变装
- 不要多替身
- 不要改成卡通化、二次元化或通用广告模特脸

## 推荐写法

### 短版

```text
严格参考这位真人素材，严格保持原有人物身份稳定，严格保持原有人物大型轮廓、面型结构、五官位置、眼神、体型、体态、发型、服装和整体气质稳定，不要换脸，不要改服装，不要改变体态，不要变成另一个演员。
```

### 长版

```text
严格参考这位真人素材，严格保持原有人物身份稳定，严格保持原有人物大型轮廓、面型结构、五官位置、眼神、肤色、体型、身材比例、发型、服装款式、服装颜色、配饰、年龄感和整体气质稳定。保持人物真人识别度和原始人物特征，不要换脸，不要改服装，不要改变体态，不要改变年龄感，不要年轻化，不要美颜化，不要网红化，不要变装，不要多替身，不要把人物泛化成另一个演员或模特。
```

## 推荐拼接方式

把“保真人锁定句”放在提示词最前面，再接场景、动作、镜头、光线。

标准顺序：

1. 保真人锁定句
2. 场景
3. 动作
4. 镜头语言
5. 光线氛围
6. 收尾状态

## 示例

```text
严格参考这位真人素材，严格保持原有人物身份稳定，严格保持原有人物大型轮廓、面型结构、五官位置、眼神、体型、体态、发型、服装款式和整体气质稳定，不要换脸，不要改服装，不要改变体态，不要年轻化，不要美颜化，不要网红化，不要变装，不要多替身，不要变成另一个演员。场景在真实办公室，人物自然看向镜头并向前走两步，右手轻微抬起示意，镜头缓慢推进，光线真实柔和，结尾停在人物半身正对镜头的稳定状态。
```

## 检查清单

- 是否在第一句就锁定了真人身份
- 是否写明了大型轮廓、面型结构、五官位置、眼神、年龄感、体态、服装不能随意修改
- 是否避免了“参考一下风格”这种太弱的说法
- 是否避免为了强动作或强风格而牺牲人像一致性
