# Desktop Posting Guide

This guide explains the practical Mac WeChat Moments publish flow and clearly marks inference where needed.

## What Is Solid vs Inferred

Solid:

- Mac WeChat supports Moments publishing in public release history by `3.1.1`.
- The current Mac App Store history still shows active Moments-related capabilities.

Inferred:

- The exact current publish path on Mac desktop is likely:
  1. Open WeChat on Mac
  2. Click the `朋友圈` entry in the left sidebar
  3. In the Moments page, click the compose / camera control near the upper-left area
  4. Add text and media
  5. Publish

This is inferred from:

- the unified desktop UI note in Mac App Store `4.0.6`
- public desktop reports that describe the desktop Moments entry and compose action

## Recommended Operating Procedure

1. Confirm the installed version is current enough.
2. Open WeChat and look for `朋友圈` in the left sidebar.
3. Enter the Moments page.
4. Look in the upper-left portion of the Moments page for the publish control.
5. Use the system file picker or drag media as allowed by the current UI.
6. Add the caption text.
7. Publish and verify the new item appears in the feed or your Moments album.

## If The Entry Is Missing

- Update WeChat first.
- Re-launch the app and sign in again.
- Confirm you are on the standard consumer WeChat Mac client.
- If the version is modern but the entry is still missing, treat it as a UI rollout difference or account-side variation until verified otherwise.

## If The Page Opens But You Cannot Publish

- Compare the current UI with the desktop compose path above.
- Confirm you are in the Moments page, not a browse-only subview.
- Check whether the version is old enough to lack the specific interaction you expect.
- Re-open WeChat after update if the app was already running during upgrade.

## Safe Answer Pattern

When responding to users, prefer wording like:

`Mac 微信现在可以发朋友圈。公开报道显示 2021 年的 3.1.1 正式版已经支持发朋友圈；当前 App Store 版本历史也持续出现朋友圈相关能力。当前桌面入口通常是左侧朋友圈 -> 朋友圈页里的发布按钮，但具体位置我会建议按你当前版本现场核一下。`
