# 小云雀 founder 口播提示词标准

适用场景：大陈 founder-IP `30 秒`竖屏中文口播短视频  
当前版本：`2026-04-25`

## 使用规则

当任务是给小云雀输出提示词、改提示词、补变量或整理成可作为 API `message` 发送的 prompt package 时，默认使用本模板。

默认输出顺序：

1. `主题文案`
2. `封面制作专用文案`
3. `核心母题`
4. `核心判断`
5. `建议口播内容`
6. 可作为 API `message` 发送的完整提示词
7. 必要时补一份简短检查清单

## 固定规则

- 视频规格：`30秒`、`9:16竖屏`、中文口播短视频
- 主角：`大陈`
- 辅助角色：`小丽`
- 角色关系：`大陈主讲 + 小丽辅助出镜`
- 绝不做成双主角
- 如果双人物参考图有冲突，优先保证大陈的人脸、发型、眼镜、白衬衫和气质稳定
- 字幕要求：`单行字幕`
- 每行字幕控制在 `8个中文字符以内`

## 参考图路径

原始标准路径：

- 大陈：`/Users/z/Downloads/新媒体素材/大陈.jpg`
- 小丽：`/Users/z/Downloads/新媒体素材/小丽.png`

本机已验证可用回退路径：

- 大陈：`/Users/baishangjituan/Downloads/素材/小云雀/人物素材/大陈.jpg`
- 小丽：`/Users/baishangjituan/Downloads/素材/小云雀/人物素材/小丽.png`

Windows handoff 等价写法：

- 大陈：`C:/Users/<name>/Downloads/素材/小云雀/人物素材/大陈.jpg`
- 小丽：`C:/Users/<name>/Downloads/素材/小云雀/人物素材/小丽.png`
- 大陈：`C:/Users/<name>/Downloads/素材/小云雀/大陈.jpg`
- 小丽：`C:/Users/<name>/Downloads/素材/小云雀/小丽.png`

Windows 路径规则：

- 所有参考图、导出目录、handoff 文档中的本地路径都使用带引号的 `C:/...` 绝对路径
- 不要把 `/Users/...`、`%USERPROFILE%` 或未加引号的含空格路径直接留给 Windows 执行人

## 首帧与封面规则

- 视频开头 `0到2秒` 必须是清晰可读的 `title poster`
- 首帧主画面必须是 `大陈正面`
- 主题文案必须直接叠在首帧上
- 主题文案建议 `6到8个中文字符`
- 另行提供一个 `封面制作专用文案`，长度建议 `6到10个中文字符`
- `主题文案` 负责视频首帧，`封面制作专用文案` 负责后续静态封面
- 两者判断方向要一致，但不要求完全同一句
- 首帧风格是 `真实视频截图感 + 简洁有设计感的文字`
- 不要做成参考图拼贴海报
- 不要让首帧只剩背景、侧脸、半张脸或看不清大陈

## 主题文案写法

主文案优先用短判断句：

- `别先裁人`
- `先拆流程`
- `先配AI员工`
- `别把AI用错`
- `AI先替劳动`
- `先把流程跑顺`

如果要两行：

- 第一行更短更狠
- 第二行补结果或动作

例如：

- `别先裁人`
- `先拆流程`

或：

- `先配AI员工`
- `再谈扩团队`

## 封面制作专用文案写法

封面制作专用文案默认单独输出，不和首帧主题文案混用。

写法要求：

- 长度控制在 `6到10个中文字符`
- 比 `主题文案` 稍完整一点，但仍然要短
- 适合压在静态封面上，一眼能看懂冲突或判断
- 不写空泛口号，不写太虚的概念词

推荐方向：

- `很多团队输在第一步`
- `先拆流程再上AI`
- `别让AI先替人`
- `不是工具强就有效`

## 变量模板

直接替换这四个变量：

- `{{主题文案}}`：建议 `6到8个字`
- `{{封面制作专用文案}}`：建议 `6到10个字`
- `{{核心母题}}`：一句完整问题或冲突
- `{{核心判断}}`：一句 founder 判断句

推荐判断骨架：

- `第一步就做错了`
- `别先裁人`
- `先拆流程`
- `先替劳动`

情绪句只适合放在前 `2到3秒` 做 hook，`第3秒后` 要尽快回到判断和方法。

## 建议口播内容标准

默认单独输出一段 `建议口播内容`，不把它混在变量说明里。

写法要求：

- 默认控制在 `10到14` 行短句
- 每句尽量短，优先写成后续可直接转单行字幕的句子
- 第 `1到2` 行要先给问题或后果
- 第 `3到5` 行内必须打出一句更硬的判断
- 中段默认给 `2到3` 个具体动作、例子或任务
- 结尾必须回到 founder 式结论，不要停在空泛口号

优先结构：

1. 先讲现实后果
2. 再讲判断句
3. 再给三个具体动作
4. 最后收一句结论

示例骨架：

- `很多团队上AI没效果`
- `不是工具不够强`
- `是第一步就做错了`
- `先拆流程`
- `再配AI员工`
- `内容初稿先给AI`
- `标准答疑先给AI`
- `纪要复盘先给AI`
- `人回到判断和成交`

## 最近复盘补充规则

最近一轮内容复盘后，后续小云雀提示词默认再收紧这 5 条：

- 保留 `founder 判断 + 结构清晰 + 现实问题感`，这是当前最稳的内容骨架
- 前 `2到3秒` 不只要有情绪，还要有 `现实后果` 或 `失败结果`，不要只做空泛焦虑
- 第 `5秒前` 必须明确打出一句更硬的判断句，比如：
  - `不是模型不行，是顺序错了`
  - `很多团队输在第一步`
  - `先拆流程，再上AI`
- 中段尽量用 `判断句 + 三个具体例子`，减少大段解释和抽象概念
- 连续几轮内容不要反复把同一句口号直接当主标题；如果前一轮已经用了 `先替劳动，不先替人`，下一轮优先换成新的判断表达

优先保留的真实业务例子：

- 写内容初稿
- 回标准客户问题
- 做会议纪要、周报和复盘

优先争取的评论信号：

- `我们公司就是这样`
- `这一步具体怎么落地`
- `先从哪类工作开始最合适`

## 复盘高占比倾向输入

当工作区已经有最新一轮复盘文件时，生成提示词前先补这 6 项：

- `上一轮最稳的平台`
- `上一轮最弱的平台`
- `上一轮图文高占比母题`
- `上一轮视频高占比主题文案`
- `上一轮必须保留的三个具体任务`
- `上一轮必须避免的标题或开头`

如果复盘里已经明确写了 `下一批小云雀视频高占比倾向`，默认优先级高于自由发挥。

这里要按“先通用视频生成，后小云雀适配”的顺序使用：

- 先继承 `主题文案优先`
- 再继承 `高占比核心母题` 和 `高占比核心判断`
- 再继承 `核心冲突句`、`核心场景 / 动作`、`开头高占比规则`
- 最后才看 `小云雀执行补充`

不要把这个区块误读成“小云雀 UI 专用建议”。它首先是给所有视频生成链路用的创意简报。

优先继承的复盘结论类型：

- 哪种开头后果句最容易挂住
- 哪种主题文案太抽象，不该继续复用
- 哪三个业务例子最该重复出现
- 哪个平台已经证明这条判断更容易被接住
- 哪句 founder 判断应该在第 5 秒前出现

## 标准完整提示词

下面内容用于小云雀 API 的 `message` 字段，不是网页粘贴操作说明。

```text
生成一条 30 秒、9:16 竖屏、中文 founder 口播短视频。

请同时使用我上传的两张参考图：
- 大陈：主角、主讲、主要出镜人物
- 小丽：助理、辅助角色、只短暂出镜

角色层级要求：
- 大陈必须是绝对主角，镜头占比最高，正面半身和中近景最多
- 小丽只作为助理出现，不要做成双主角，不要抢走大陈的戏份
- 如果双人物参考图有冲突，优先保证大陈的脸、发型、眼镜、白衬衫和气质稳定

首帧与片头要求：
- 视频开头前 0 到 2 秒必须做成清晰的 title poster
- 首帧主画面必须是大陈正面，正脸清晰、眼神稳定、人物居中或偏中
- 不要用静态参考图直接做海报感封面，要像真实视频中的一个定格瞬间
- 首帧上直接叠加主题文案：{{主题文案}}
- 主题文案控制在 6 到 8 个中文字符
- 文字大、短、易读，可以有设计感，但不要过度设计
- 文字可以压在人物中部区域，但不要完全挡住五官

内容方向：
- 前 2 到 3 秒允许有冲突或情绪张力
- 但第 3 秒后必须立刻切回大陈正面表达判断和方法
- 核心母题：{{核心母题}}
- 核心判断：{{核心判断}}

剧情结构：
- 0 到 2 秒：先出现大陈正面 title poster，直接打出主题文案 {{主题文案}}
- 2 到 5 秒：快速给冲突、误区或错误做法
- 5 到 15 秒：大陈直接拆判断，不讲空话
- 15 到 24 秒：给出 2 到 3 个具体动作、步骤或任务
- 24 到 30 秒：大陈收尾，给出一句 founder 式结论

场景要求：
- 现代中国创业公司办公室
- 玻璃会议室、办公桌、白板、电脑、城市景观
- 真实、克制、日常，不要广告棚拍感

镜头要求：
- 大陈：正面中近景、半身镜头为主，少量走动和手势
- 小丽：只在开场或过场辅助出现，可以拿文件、平板、方案，不要独立长时间讲话
- 节奏快，3 秒内进入判断句

口播要求：
- 大陈主讲
- 句子短、判断清楚、少形容词、多动作词
- 不要讲模型参数，不要讲抽象行业黑话

字幕要求：
- 单行字幕
- 每行不超过 8 个中文字符
- 字幕短、狠、清楚

禁止项：
- 不要做成双主角
- 不要让小丽抢戏
- 不要科幻机甲风
- 不要品牌 logo 墙
- 不要把首帧做成只剩背景
- 不要让大陈首帧不是正面
```

## 首次生成失败后的返工矩阵

如果第一次生成结果不对，不要只笼统地说“再优化一下”，直接按问题类型收紧提示词。

### 1. 人脸不稳

- 强化 `大陈必须是绝对主角`
- 强化 `正面半身和中近景最多`
- 减少小丽镜头，必要时降到只在过场出现
- 明确 `优先保证大陈的脸、发型、眼镜、白衬衫和气质稳定`

### 2. 首帧不对

- 强化 `0到2秒必须是大陈正面 title poster`
- 强化 `首帧主画面必须是正脸清晰、人物居中或偏中`
- 禁止 `侧脸、背身、半张脸、只剩背景`

### 3. 太像广告片

- 删除或禁止 `舞台感、品牌墙、棚拍感、发布会感`
- 强化 `真实、克制、日常的中国创业公司办公室`
- 强化 `像真实口播视频，不像广告宣传片`

### 4. 口播太空

- 中段必须补 `2到3个具体动作`
- 少讲抽象概念，多讲 `写内容初稿 / 回标准客户问题 / 做纪要复盘` 这类任务
- 第 `5秒前` 必须补一句硬判断

### 5. 字幕太长

- 继续收紧 `单行字幕`
- 强化 `每行 8 个中文字符以内`
- 把长句拆成短判断句，不要一行塞完整解释

### 6. 没有封面帧

- 强化 `结尾或中段必须保留清晰正面或半身定格瞬间`
- 强化 `适合后续截图做封面`
- 禁止 `大动作中截帧、模糊脸、嘴型变形`

## 生成后检查清单

- 首帧是不是大陈正面
- 首帧主题文案是不是清晰可读
- 封面制作专用文案是不是 `6到10字` 且适合静态封面
- 建议口播内容里有没有 `第5秒前` 的硬判断句
- 建议口播内容里有没有 `2到3` 个具体动作或业务例子
- 大陈是不是绝对主角
- 小丽是不是只作为助理辅助出现
- 字幕是不是单行且 8 字以内
- 前 3 秒是不是足够抓人
- 第 5 秒前是不是已经进入判断句
- 后半段是不是给了具体动作，不只是情绪演绎
